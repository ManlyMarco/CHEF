Your user ID can be stored on an external server if you use any of the bot commands that require this to function. If you do not use any of the bot commands this will not happen. This data is never shared and is occasionally purged.

No other data is stored outside of Discord.

Message content can be stored on Discord to help with moderation, e.g. when a user is banned. This data is never shared outside of the server's moderation team.

If you DM the bot your messages will not be looked at by anyone but they are not removed.
